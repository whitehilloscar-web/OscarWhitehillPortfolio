# Oscar Whitehill Portfolio — River & Wing update

This is the complete static website. Upload the **contents of this folder**, not the ZIP itself, to the root of your GitHub Pages repository. Keep the `assets/` and `projects/` folders intact.

### What's new
- New **River & Wing** brand case study: `projects/river-and-wing.html`, with 11 optimised presentation pages and a cropped flask thumbnail.
- River & Wing is now the first project on the homepage.
- Removed Buried from the project grid and excluded its project page and images from the new website files.
- Small changes to homepage biography and availability text to encompass visual design roles.

### Important: remove obsolete files from your existing repository
Uploading replacement files in GitHub **does not automatically delete** files that already exist. Delete `projects/buried.html` and `assets/buried-original.webp`, `assets/buried-poster.webp`, `assets/buried-process.webp` in your existing GitHub repository if you want Buried completely gone. You can also use `git` to delete/commit them.

### GitHub Pages
If Pages is not already enabled, go to **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`, then save.
