Project overview

The kit uses reusable wall, roof, window, trim and gutter modules built on a consistent grid. Tileable materials and mask-based variation support multiple buildings without producing a separate texture set for every asset.

The final environment will demonstrate assembly, material variation and how the modules can produce a believable wider streetscape.

Next step: add the strongest current Unreal Engine image, followed by the kit layout, material graph and building variations.
